Census and area data

Author
Affiliation

Vagish Hemmige

MAHV

This page is part of the study’s design and methods. The Specified in and Current code notes are explained on the Overview, and the general background is on Data sources and Statistical methods. The code is on 1. Public area data and 4. Linking area data.

Abbreviations: ACS, American Community Survey; HSA, Hospital Service Area; RUCA, Rural-Urban Commuting Area; USRDS, United States Renal Data System; ZCTA, ZIP Code Tabulation Area.

Each patient is placed by the residential ZIP code in effect on the day dialysis started. Everything known about the area where they lived is attached through that ZIP code: the census characteristics of their neighbourhood, their Hospital Service Area (HSA) and its population, the HSA’s care measures, and how rural the ZIP code is. The dialysis facilities around them, also counted on that day, are on Dialysis facilities. Every source except USRDS is public and is downloaded from its publisher.

One date for everything

All area data are matched to the year dialysis started, the same date that sets the facility count, so a patient’s facilities, population and neighbourhood describe the same moment. The original code matched area data to the year of the Medical Evidence form instead, and its facility join quietly dropped patients whose two years differed; this analysis corrects this (decided by Vagish Hemmige, 27 October 2026).

Specified in: §3 Data source, §4 Study population (“Year of linkage”).

Census data through the ZCTA

The American Community Survey (ACS) reports by ZIP Code Tabulation Area (ZCTA), not by ZIP code, and not every ZIP code has a ZCTA of its own (U.S. Census Bureau, n.d.). Each patient’s ZIP code is therefore mapped to its ZCTA with the UDS Mapper crosswalk for the year dialysis started (UDS Mapper, n.d.; Prener et al. 2026), and the ZCTA’s ACS 5-year estimates for that year are attached from subject table S0601 (Walker and Herman 2026): the ZCTA’s population and characteristics such as the share of Black residents and the share below the poverty line. Matching ZIP codes to ZCTAs by number alone, as the original code did, would lose everyone in a ZIP code whose ZCTA has a different number.

Specified in: §3 Data source, §6 Covariates.

The HSA and its population

The Dartmouth Atlas crosswalk for the same year places each ZIP code in an HSA (The Dartmouth Atlas of Health Care, n.d.-c). The HSA’s population, the denominator of the exposure, is the ACS population of the ZCTAs of the ZIP codes in the HSA that year. Several ZIP codes can share a ZCTA, so each ZCTA is counted once per HSA; summing over ZIP codes would count a shared ZCTA’s population several times. A patient whose HSA has no ACS population has no facility density and is excluded at the HSA step.

Specified in: §5 Exposure.

Current code: the HSA step removes these patients together with those whose ZIP code has no HSA (Linking area data).

HSA care measures and rural-urban type

The Dartmouth Atlas’s primary care measures (2015) and hospital resources (2012) are attached by HSA (The Dartmouth Atlas of Health Care, n.d.-b, n.d.-a); values coded as too small or suppressed are treated as missing, not as numbers. The Economic Research Service’s 2010 RUCA ZIP code file gives each ZIP code a primary code, grouped as metropolitan, micropolitan, small town or rural (USDA Economic Research Service 2020, n.d.). These are fixed measures, not matched by year.

Specified in: §3 Data source, §6 Covariates.
